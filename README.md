# Fósforo

Editor de texto em tela cheia com cara de terminal CRT, em fósforo verde, âmbar ou branco. É um arquivo HTML só, sem servidor e sem conta.

**Abrir:** https://fperuzzo72.github.io/fosforo/

## Como usar

- **ESC** (ou **⌘.** no iPad) abre o menu. Tudo é gravado sozinho enquanto você escreve.
- Metas por palavras, caracteres ou minutos; estatísticas; versões anteriores; modo Hemingway (sem apagar); prévia em Markdown; exportação em .txt, .md, .html e PDF.

### No computador, com uma pasta (Chrome, Edge e parecidos)

Baixe o `fosforo.html`, ponha ao lado de uma pasta `fosforo-dados` (no iCloud Drive, por exemplo) e escolha essa pasta na primeira vez. Cada texto vira um arquivo `.md` em `fosforo-dados/textos/`.

### No iPad, no iPhone e no Safari

Esses navegadores não gravam numa pasta, então os textos ficam no próprio navegador. Abra o endereço acima e use **Compartilhar > Adicionar à Tela de Início**: assim ele abre sem internet e o Safari não apaga os dados por falta de uso.

Faça backups de tempos em tempos (ESC > X > B): o `.zip` leva o editor e todos os dados. Para restaurar ou levar a outro aparelho, ESC > X > R:

- **Juntar**: textos novos entram; quando o mesmo texto existe nos dois lados, fica o mais recente e o outro vira uma versão.
- **Substituir tudo**: o que havia vai para a lixeira, e dá para trazer de volta.

Um backup feito no computador também leva as letras e os sons da pasta `fosforo-dados` para o iPad.
